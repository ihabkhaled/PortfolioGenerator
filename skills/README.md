# skills/

Procedures for the changes that touch more than one file and have a right order.

They exist because each of these has a step that is easy to forget and quiet
when forgotten — a lint config that also needs updating, a snapshot that also
needs regenerating, a surface that also needs exporting.

| Skill                                                            | For                                   |
| ---------------------------------------------------------------- | ------------------------------------- |
| [add-a-module.md](./add-a-module.md)                             | A new feature area                    |
| [add-a-vendor-package.md](./add-a-vendor-package.md)             | A new third-party dependency          |
| [change-the-document-schema.md](./change-the-document-schema.md) | Changing what a portfolio can contain |
| [add-a-section-type.md](./add-a-section-type.md)                 | A new kind of band on a page          |
| [investigate-a-failing-gate.md](./investigate-a-failing-gate.md) | When `npm run validate` fails         |
| [communicate-briefly.md](./communicate-briefly.md)               | Every message you send                |

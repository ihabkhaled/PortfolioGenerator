# Admin Portal Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a genuinely isolated `/managawy` admin auth system — its own `better-auth` instance, its own Prisma tables, mandatory TOTP 2FA, a role/permission model, a non-touchable seeded super admin, and an audit trail — with a working sign-in flow and a minimal dashboard-home stats page. No user/portfolio management UI yet (Phase 2).

**Architecture:** A second `betterAuth()` instance (`src/packages/admin-auth/`) points at five brand-new Prisma models with zero foreign keys to the existing `User`/`Session`/`Account`/`Verification` tables, its own cookie (`managawy.session_token`), its own API base path (`/api/managawy-auth`), and mandatory TOTP via better-auth's `two-factor` plugin. A new `src/modules/admin` module owns permission resolution, session/2FA-aware auth guards, and audit logging. `/managawy` is registered as a reserved platform route (not a portfolio slug), gets its own stricter CSP branch in `proxy.ts`, and is fully `noindex`/`no-store`. A one-time idempotent script seeds the super admin in production via `vercel-build`, never via a SQL migration (SQL can't call better-auth's password hasher).

**Tech Stack:** Next.js 16 App Router, Prisma 7 + Postgres, `better-auth` 1.6.26 (`two-factor` plugin), `qrcode` (new dependency, server-side SVG rendering only — the TOTP secret never leaves the server-to-browser response), Playwright for E2E, Vitest for unit tests.

**Spec:** `docs/superpowers/specs/2026-08-13-admin-portal-foundation-design.md` — read it in full before starting; this plan does not repeat its reasoning, only its conclusions as executable steps.

## Global Constraints

- Route is `/managawy`, never `/admin` or `/administrator` (already defensively reserved words in `slug.constants.ts`, unrelated to this route).
- The `AdminUser`/`AdminSession`/`AdminAccount`/`AdminVerification` core fields (the exact set better-auth itself manages) get **no** `@map` — mirroring the existing `User`/`Session`/`Account`/`Verification` models exactly, where only app-added fields (`isSuperAdmin`, `status`, timestamps on app-owned tables) are `@map`'d to snake_case. Every model still gets `@@map` to a snake_case table name.
- `isSuperAdmin` is set to `true` by exactly one code path ever: the seed script. No action, ever, sets it to `true` or `false`.
- Public HTTP sign-up for the admin instance must be blocked at the route-handler level — the only way an `AdminUser` row is created in this phase is the seed script calling `api.signUpEmail` in-process (never through the HTTP route).
- 2FA is mandatory: a session with `twoFactorEnabled === false` must never reach any real `/managawy` page except the enrollment screen.
- Every `/managawy` response carries `Cache-Control: private, no-store, max-age=0` and `X-Robots-Tag: noindex, nofollow`, unconditionally.
- Run `npm run lint` and `npm run typecheck:app` after every task that touches `.ts`/`.tsx` files — don't wait until the end to discover an architecture-lint violation.
- Never add an `eslint-disable` comment. If a rule is a genuine false positive, the exception goes in `eslint/exceptions.config.mjs` with an id and a reason (see existing entries for the pattern).

- [ ] **Step 5: Write `admin-authorization.policy.ts`**

```ts
import type { AdminPermission } from '@prisma/client';

import type { AuthenticatedAdmin } from '../types/admin.types';

/**
 * The one place "can this admin do X" is answered.
 *
 * A suspended admin has zero permissions regardless of role or the
 * super-admin flag — suspension is a full stop, not a soft warning — and a
 * super admin has every permission unconditionally, which is what makes
 * "non-touchable" meaningful: the super admin can never accidentally lock
 * themselves out by an RBAC edit that only ever touches `permissions`.
 */
export function hasAdminPermission(
  admin: AuthenticatedAdmin,
  permission: AdminPermission,
): boolean {
  if (admin.status === 'SUSPENDED') return false;
  if (admin.isSuperAdmin) return true;

  return admin.permissions.includes(permission);
}

/**
 * The non-touchable-super-admin guard. Every action that would modify,
 * suspend or delete an `AdminUser` calls this on the *target* row before
 * doing anything else, regardless of what the caller is otherwise allowed
 * to do — `ADMINS_MANAGE` grants managing admins in general, never this one.
 */
export function assertNotSuperAdmin(target: { readonly isSuperAdmin: boolean }): void {
  if (target.isSuperAdmin) {
    throw new Error('The super admin account cannot be modified.');
  }
}
```

```ts
import 'server-only';

import { headers } from 'next/headers';

import { getDatabase } from '@/packages/database';
import { logger } from '@/packages/logger';
import { getAdminAuth } from '@/packages/admin-auth/server';
import { appRedirect } from '@/packages/navigation';
import { ROUTE_PATHS } from '@/shared/constants/route-paths.constants';

import { toAuthenticatedAdmin } from '../mappers/admin-user-to-authenticated-admin.mapper';
import { hasAdminPermission } from '../policies/admin-authorization.policy';
import type { AuthenticatedAdmin } from '../types/admin.types';

/**
 * Session resolution for the isolated admin auth instance.
 *
 * Two levels, deliberately distinct: `getOptionalAdminSession` answers "is
 * there a password-authenticated admin session at all" — used only by the
 * sign-in flow and the 2FA enrollment page, both of which must render for an
 * admin who has passed their password check but not yet completed 2FA.
 * `getOptionalAdmin` answers "is this admin fully authenticated for the
 * dashboard" — session *and* `twoFactorEnabled === true` — and is what every
 * real management page and action calls.
 */
export async function getOptionalAdminSession(): Promise<AuthenticatedAdmin | null> {
  try {
    const requestHeaders = await headers();
    const session = await getAdminAuth().api.getSession({ headers: requestHeaders });

    if (!session?.user) {
      return null;
    }

    const row = await getDatabase().adminUser.findUnique({ where: { id: session.user.id } });

    if (!row) {
      return null;
    }

    return toAuthenticatedAdmin(row);
  } catch (error) {
    logger.warn('admin.session.lookup_failed', {
      reason: error instanceof Error ? error.name : 'unknown',
    });

    return null;
  }
}

export async function getOptionalAdmin(): Promise<AuthenticatedAdmin | null> {
  const requestHeaders = await headers();

  try {
    const session = await getAdminAuth().api.getSession({ headers: requestHeaders });

    if (!session?.user || session.user.twoFactorEnabled !== true) {
      return null;
    }
  } catch {
    return null;
  }

  return getOptionalAdminSession();
}

/**
 * The authorization boundary for a `/managawy` page or action.
 *
 * Three outcomes: no session at all → sign-in. A session that has not
 * completed 2FA yet → the enrollment screen, never the requested page.
 * A fully authenticated admin who lacks the specific permission → thrown
 * error (this one is not a redirect: it means a UI bug let an admin reach a
 * control they should never have seen, and that is worth surfacing loudly
 * rather than silently bouncing them).
 */
export async function requireAdmin(permission: AdminPermission): Promise<AuthenticatedAdmin> {
  const sessionAdmin = await getOptionalAdminSession();

  if (!sessionAdmin) {
    appRedirect(ROUTE_PATHS.managawySignIn);
  }

  const requestHeaders = await headers();
  const session = await getAdminAuth().api.getSession({ headers: requestHeaders });

  if (session?.user.twoFactorEnabled !== true) {
    appRedirect(ROUTE_PATHS.managawyTwoFactorEnroll);
  }

  if (!hasAdminPermission(sessionAdmin, permission)) {
    throw new Error(`Missing admin permission: ${permission}`);
  }

  return sessionAdmin;
}
```

```ts
import { getDatabase } from '../src/packages/database/index.ts';
import { getAdminAuth } from '../src/packages/admin-auth/server.ts';
import { getServerEnv } from '../src/packages/env/server.ts';
import { DEFAULT_ROLE_PERMISSIONS } from '../src/modules/admin/server.ts';

/**
 * Seeds exactly one super admin, exactly once, ever.
 *
 * Idempotency is "does any AdminUser with isSuperAdmin=true already exist",
 * not an upsert-by-email: an upsert would risk resetting an already-seeded
 * super admin's password on a later deploy just because ADMIN_SEED_PASSWORD
 * is still set in the environment. This script costs one indexed COUNT query
 * on every deploy after the first successful run, forever.
 *
 * Wired into `vercel-build` — runs on every production deploy. Not a Prisma
 * migration: a raw SQL migration cannot call better-auth's own password
 * hasher, and this script's whole point is that the seeded hash and the
 * admin-auth instance's own verification must never drift apart.
 */
```

```ts
'use server';

import QRCode from 'qrcode';

import { appRedirect } from '@/packages/navigation';
import { logger } from '@/packages/logger';
import { ROUTE_PATHS } from '@/shared/constants/route-paths.constants';

import { getAdminAuth } from '@/packages/admin-auth/server';

import { getOptionalAdminSession } from '../services/admin-session.service';
import { recordAdminAuditEvent } from '../services/admin-audit.service';
import {
  ADMIN_SIGN_IN_INITIAL_STATE,
  type AdminSignInFormState,
  type AdminTwoFactorEnrollment,
} from '../types/admin-auth-view.types';

/**
 * Password step. Two outcomes better-auth itself distinguishes: an ordinary
 * session (no 2FA enrolled yet — the account proceeds to mandatory
 * enrollment) or a `twoFactorRedirect` marker (2FA already enabled — no
 * session cookie is set until `adminVerifyTwoFactorAction` succeeds).
 */
export async function adminSignInAction(
  _previous: AdminSignInFormState,
  formData: FormData,
): Promise<AdminSignInFormState> {
  const email = formData.get('email');
  const password = formData.get('password');

  if (
    typeof email !== 'string' ||
    typeof password !== 'string' ||
    email === '' ||
    password === ''
  ) {
    return { status: 'error', error: 'Enter your email and password.' };
  }

  try {
    const result = await getAdminAuth().api.signInEmail({
      body: { email, password },
      asResponse: false,
    });

    if ('twoFactorRedirect' in result && result.twoFactorRedirect) {
      return { status: 'needs-two-factor', error: null };
    }
  } catch {
    logger.warn('admin.sign_in.rejected');
    return { status: 'error', error: 'Incorrect email or password.' };
  }

  const admin = await getOptionalAdminSession();

  if (admin) {
    await recordAdminAuditEvent({
      adminUserId: admin.id,
      targetType: 'ADMIN_USER',
      targetId: admin.id,
      action: 'admin.session.created',
    });
  }

  appRedirect(ROUTE_PATHS.managawyTwoFactorEnroll);
}

export async function adminVerifyTwoFactorAction(
  _previous: AdminSignInFormState,
  formData: FormData,
): Promise<AdminSignInFormState> {
  const code = formData.get('code');

  if (typeof code !== 'string' || code === '') {
    return { status: 'needs-two-factor', error: 'Enter the 6-digit code.' };
  }

  try {
    await getAdminAuth().api.verifyTOTP({ body: { code } });
  } catch {
    return { status: 'needs-two-factor', error: 'That code did not match. Try again.' };
  }

  const admin = await getOptionalAdminSession();

  if (admin) {
    await recordAdminAuditEvent({
      adminUserId: admin.id,
      targetType: 'ADMIN_USER',
      targetId: admin.id,
      action: 'admin.two_factor.verified',
    });
  }

  appRedirect(ROUTE_PATHS.managawy);
}

/**
 * Starts enrollment: better-auth issues a fresh TOTP secret and backup
 * codes, requiring the current password again as its own confirmation step.
 * Rendered as a QR code server-side — the secret is never sent to any
 * third-party service, only from this server to this admin's own browser.
 */
export async function adminStartTwoFactorEnrollmentAction(
  password: string,
): Promise<AdminTwoFactorEnrollment> {
  const result = await getAdminAuth().api.enableTwoFactor({
    body: { password, issuer: 'ProFolio Admin' },
  });
  const qrCodeSvg = await QRCode.toString(result.totpURI, { type: 'svg', margin: 1 });

  return { totpUri: result.totpURI, qrCodeSvg, backupCodes: result.backupCodes };
}

export async function adminConfirmTwoFactorEnrollmentAction(
  _previous: AdminSignInFormState,
  formData: FormData,
): Promise<AdminSignInFormState> {
  const code = formData.get('code');

  if (typeof code !== 'string' || code === '') {
    return { status: 'error', error: 'Enter the 6-digit code from your authenticator app.' };
  }

  try {
    await getAdminAuth().api.verifyTOTP({ body: { code } });
  } catch {
    return { status: 'error', error: 'That code did not match. Try again.' };
  }

  const admin = await getOptionalAdminSession();

  if (admin) {
    await recordAdminAuditEvent({
      adminUserId: admin.id,
      targetType: 'ADMIN_USER',
      targetId: admin.id,
      action: 'admin.two_factor.enrolled',
    });
  }

  appRedirect(ROUTE_PATHS.managawy);
}
```

```ts
export interface AdminDashboardStatsCounts {
  readonly totalUsers: number;
  readonly totalPortfolios: number;
  readonly publishedPortfolios: number;

  readonly unpublishedPortfolios: number;
```

```tsx
import type { ReactElement } from 'react';

import { getDatabase } from '@/packages/database';

import { adminShellClasses } from '@/modules/admin/constants/admin-shell-style.constants';
import { buildAdminDashboardStats } from '@/modules/admin/helpers/admin-stats.helper';
import { requireAdmin } from '@/modules/admin/server';

const THIRTY_DAYS_MS = 30 * 24 * 60 * 60 * 1000;

export default async function AdminDashboardPage(): Promise<ReactElement> {
  await requireAdmin('USERS_VIEW');

  const database = getDatabase();
  const thirtyDaysAgo = new Date(Date.now() - THIRTY_DAYS_MS);

  const [
    totalUsers,
    totalPortfolios,
    publishedPortfolios,
    draftPortfolios,
    unpublishedPortfolios,
    signupsLast30Days,
  ] = await Promise.all([
    database.user.count(),
    database.portfolio.count({ where: { deletedAt: null } }),
    database.portfolio.count({ where: { deletedAt: null, status: 'PUBLISHED' } }),
    database.portfolio.count({ where: { deletedAt: null, status: 'DRAFT' } }),
    database.portfolio.count({ where: { deletedAt: null, status: 'UNPUBLISHED' } }),
    database.user.count({ where: { createdAt: { gte: thirtyDaysAgo } } }),
  ]);

  const stats = buildAdminDashboardStats({
    totalUsers,
    totalPortfolios,
    publishedPortfolios,
    draftPortfolios,
    unpublishedPortfolios,
    signupsLast30Days,
  });

  return (
    <div className={adminShellClasses.statsGrid}>
      {stats.map((stat) => (
        <div key={stat.id} className={adminShellClasses.statTile}>
          <span className={adminShellClasses.statLabel}>{stat.label}</span>
          <span className={adminShellClasses.statValue}>{stat.value}</span>
        </div>
      ))}
    </div>
  );
}
```
